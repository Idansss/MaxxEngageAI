# Governance Notes

Maxx Engage begins founder-led, but it should not remain founder-dependent.

## Current Stage

Phase 1 is still focused on the Competence Engine. Governance is lightweight:

- Public repository.
- Public manifesto and technical spec.
- Open issues for roadmap decisions.
- Discord community for discussion.
- Human review queue for credential-impacting decisions.

## Near-Term Rules

- Scoring rubric changes must be public.
- Model/provider changes must be documented.
- Credential schema changes must remain W3C VC compatible.
- Any change that affects credential issuance must preserve appealability.
- Admin actions that change scores, credentials, or appeals must be audit-logged.

## Later Governance Direction

The long-term target remains bicameral governance:

- A contribution-weighted chamber for builders and reviewers.
- A sortition chamber of verified humans to prevent capture by funders or whales.

Do not implement token voting before the core credential loop is useful to real
users. Premature governance machinery can become a distraction from evidence,
fairness, and product truth.
